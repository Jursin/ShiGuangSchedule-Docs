## 导出文件
- **课程文件导出**

  导出包含课程表、时间表、部分配置（开学日期、学期总周数、默认课程时长、默认课间休息时长）的 **json 文件**
- **日历文件导出**

  导出 **ics 文件**，点击生成指定提醒时间参数的文件

  ::: important
  注意记住**导出文件的路径**，方便后续分享或重新导入文件恢复配置
  :::

## 同步
- **同步到系统日历**

  将当前课表一键同步至手机**系统日历**
- **备份与恢复**

  支持 **WebDAV 云同步**与**本地 ZIP 文件**多渠道备份，保障课表数据安全
