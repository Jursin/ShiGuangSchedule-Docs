> **我的-高级功能-课程提醒设置**，支持以下配置

::: important
为确保 Android 提醒准时送达，你需要：
- 允许通知
- 授予**精确闹钟权限**（Android 12+）
- 允许应用自启动
- 忽略电池优化
:::

## 课程提醒
开启后，应用会在每节课开始前发出通知提醒

- 可自定义提前提醒时间（默认 15 分钟）
- 基于系统**精确闹钟**实现，确保准时触发
- 切换课表或修改课程时自动同步更新提醒
- 部分设备支持**实时更新通知**（Android 16 新特性）

## 上课自动模式
开启后，上课期间自动将手机切换为指定模式，下课后自动恢复

- **勿扰模式**：来电和通知不会有提醒
- **静音模式**：来电和通知铃声静音

::: note
- 需先开启课程提醒
- 授予勿扰模式权限
:::

## 兼容穿戴设备
开启后，课程提醒通知会同步至已连接的穿戴设备，方便快速查看课程通知

::: note
因 Android 16 实时通知属性与部分穿戴设备通知同步软件存在兼容性冲突，开启此项将优化同步兼容性，但会停用实时更新效果
:::

## 节假日同步
应用通过 API 获取全年法定节假日数据，自动标记为跳过日期，避免假期触发课程提醒

- 支持手动**更新节假日数据**
- 可**查看**或**清除**已跳过的日期

## 权限说明
| 权限 | 用途 | 所需系统版本 |
| - | - | - |
| 通知权限 | 发送课程提醒通知 | Android 13+ |
| 精确闹钟权限 | 准时触发提醒 | Android 12+ |
| 通知使用权 | 上课自动勿扰/静音 | Android 5.0+ |
| 电池优化白名单 | 防止系统杀后台导致提醒延迟 | Android 6.0+ |

权限未授予时，应用会自动引导跳转到系统设置页面进行开启
